# FoodieHub - Restaurant Ordering System
 ## Project Overview
 FoodieHub is a full-stack restaurant ordering system with automated CI/CD pipeline.
 ### Team Members
 - **Member 1**: Frontend Development (HTML, CSS, JavaScript)- **Member 2**: Backend Development (Spring Boot, REST APIs)- **Member 3**: Git &amp; Maven Configuration- **Member 4**: Jenkins CI/CD Pipeline- **Member 5**: Docker &amp; Kubernetes Deployment
 ## Technology Stack- **Frontend**: HTML5, CSS3, JavaScript- **Backend**: Java 17, Spring Boot 3.2.0- **Database**: PostgreSQL (Production), H2 (Development)- **Build Tool**: Maven- **Version Control**: Git- **CI/CD**: Jenkins- **Containerization**: Docker- **Orchestration**: Kubernetes
